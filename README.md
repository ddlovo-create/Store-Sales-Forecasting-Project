# Store‑Sales‑Forecasting‑Project
Sales Forecasting with Regression & Random Forest | Business Analytics Project for BA Application

## Project Introduction
This sales forecasting project uses the public Kaggle store sales dataset. We complete the whole workflow including data preprocessing, feature engineering, exploratory analysis and predictive modeling. By comparing linear regression and random forest regression models, we evaluate prediction performance with RMSE and MAE metrics, identify key sales drivers, and provide inventory and marketing optimization suggestions for retail business.

## Tech Stack
- SQL: Data filtering, feature derivation for holiday and promotion tags
- Python: Pandas, NumPy, Matplotlib, Seaborn, Scikit‑learn
- Model: Linear Regression (baseline), Random Forest Regressor
- Evaluation Metrics: RMSE, MAE, Feature importance analysis
